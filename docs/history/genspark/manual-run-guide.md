# 新版v2 手動実走の手順（操作者用・実走先へ添付しない）

対象：2026-09-20、P1〜P5を実装したnovel-editor（skill版 `ad40fd1`）。
旧版の結果と比較するための手動実走です。APIキーやコマンド操作は不要です。
今回の入力にはskill本文が入っているため、**実走時は既存のnovel-editor skillを無効**にします。削除は不要です。
通常利用のための新版 `.skill` インストールと、この内包入力によるテストは別の手順です。

## まず1件だけ実行するなら

1. 新版ZIPを展開し、`RUN_03_v2.txt` を取り出す。旧 `RUN_03.txt` と取り違えない。
2. **Sonnet 5・最大・シークレットの新規チャット**を開く。前回Sonnetと同じモデル・設定・添付方式に揃えられる場合の推奨です。利用できなければ無理に別モデルへ変えず、状況を記録してください。
3. 既存skillを無効にし、`RUN_03_v2.txt` **1件だけ**を添付する。
4. 下の共通メッセージを送る。
5. 最初の応答全文を、直さず・要約せず `RUN_03_v2_response.txt` などに保存する。
6. 応答と `RETURN_NOTES.txt` の実行条件を、この作業スレッドへ返す。

一度に全件を行う必要はありません。Qwenの実行は不要です。
ZIP全体、この手順書、返却メモ、manifest、評価結果、修正理由は実走先に渡しません。

## 送信する共通メッセージ

RUNファイル1件を添付して、以下だけを送ります。旧版と同じ文章です。

```text
添付ファイルを先頭から最後まで読み、その中のskillの指示と【ユーザーの依頼】に従って応答してください。ファイル自体の説明や要約ではなく、依頼への回答を日本語で返してください。
```

## 続けて実行する場合

番号とケースの対応は旧版のままです。**推奨する実行順だけが03→01→02**です。
各RUNは、それぞれ別の新規チャットで実行します。

| 順番 | 入力ファイル | 保存名 | ケースID（操作者用） |
|---|---|---|---|
| 1 | RUN_03_v2.txt | RUN_03_v2_response.txt | #13 |
| 2 | RUN_01_v2.txt | RUN_01_v2_response.txt | #15 |
| 3 | RUN_02_v2.txt | RUN_02_v2_response.txt | #14 |

前のRUNの応答や確認への回答を、次のRUNへ持ち越しません。単発3件の試験で、多ターン会話ではありません。
他モデルでも試す場合は、モデル名・設定・入力方式を記録し、応答を別ファイルで返します。

## 環境を揃えるための注意

- このCodeプロジェクトの履歴・リポジトリ・作業ロールを共有しない空の新規チャットを使います。
- 既存skillは無効。追加ロール・独自のカスタム指示・過去会話参照も可能な範囲で無効にします。
- 無効化できないもの、メモリの状態、通常／シークレットの別は返却メモに残します。
- RUN入力に必要ファイルは内包されています。別のskillファイルや原典を追加添付しません。
- 通常のチャット利用枠は消費し得ます。この準備だけでモデル実走を行ったわけではありません。

## 応答の保存

- 質問だけ、資料不足、点数なしでも最初の応答をそのまま保存します。質問に答えたり「採点まで進めて」と誘導しません。
- 再生成で良い答えを選びません。すでに再生成・追加指示した場合は最初の応答も残し、その事実を記録します。
- **本文とは別に質問カードが出た場合は、質問と全選択肢も保存**します。回答本文だけで欠けるならスクリーンショットや保存ページを併用し、選択肢は押しません。
- 長い表・引用・最後の台帳と引き継ぎを省略しません。
- 途中で切れた場合もまず保存します。「続けて」は今回の最初の実走には追加しません。
- 非公開の内部思考や隠れたログを取得する必要はありません。見えている最終回答と、必要なら読取エラーの表示だけで構いません。
- 可能なら回答のみを保存し、関係のないサイドバー・個人情報は避けます。

## 添付できない・読めない場合

その試行はいったん止め、エラーを記録してください。入力を分割・要約・省略しません。
全文貼付へ替える場合は、共通メッセージの「添付ファイル」を「以下の入力」に替え、その後にRUN全文を貼ります。
添付方式との条件差が生じるため、入力方法とメッセージ変更を記録します。制限で全文が入らない場合は無理に続行しません。
通信エラー後の再試行も、最初の試行とは区別して残します。

## 返すもの・結果の扱い

- 実行したRUNの最初の応答全文（txt/md、またはこのスレッドへの全文貼付）
- 別UI質問カードがあれば、その質問と選択肢
- 記入した `RETURN_NOTES.txt`（未実行・不明の欄はそのままで可）

旧版の6応答・56項目の記録を残し、新版を同じeval定義で照合します。各1回の結果だけで性能や再現性を断定しません。
旧版とモデル・設定・入力方式が異なる場合は、skill改訂の効果と環境差を切り分けて記録します。
